# Tuto-Arduino

Les programmes des tutoriels Arduino de la chaîne NabilByte, en vrais fichiers `.ino`.

Un dossier par tutoriel (le même nom que dans la vidéo), un croquis par programme. Ouvre le `.ino` dans l'IDE Arduino (le dossier du croquis doit garder le même nom que le fichier), ou copie le code ici : les signes `<` et `>` sont les vrais, contrairement à la description YouTube.

Carte : Arduino Uno. Les bibliothèques nécessaires sont citées en tête de chaque programme (`#include`) et se installent par le Gestionnaire de bibliothèques de l'IDE.
